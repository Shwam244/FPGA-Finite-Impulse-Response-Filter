As an introduction to signals and systems, this project has helped me learned the properties of lowpass filters as well as the challenge of converting from floating point to fixed point while also ensuring accuracy to a reference "golden" model created from MATLAB when shifting over to FPGA hardware. By design, an FIR filter in this case is meant to filter out the many impulses that come from the gaussian noise added onto the clean signal, proving to be superior compared to other filters such as an IIR filter as the coeffecients are symmeterical, preventing any phase/waveform distortion of the signal. While designing the filter in MATLAB, my biggest challenges were exporting the coeffecients and noisy signal values to verilog by converting from decimal to 16 bit hexadecimal and discovering that signals must be column vectors when passed through a filter. The latter challenge took me especially longer to solve as I had to research constantly before disocvering it on MATLAB's website where signals represented as row vectors will only pass through 1 channel instead of the 2001 channels I had defined earlier. Looking back at my code in verilog, I see many opportunites where my code can be shortened/more concise, and I plan on improving my skills with the next project I plan to do.
